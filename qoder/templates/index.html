检索层（seekdb 兼容）

文档存储与关键词检索由本地 SQLite + FTS5 完成，接口与结果结构按 seekdb 的检索模式设计，包含分类过滤与预留的向量分数字段。当前部署未连接 seekdb 服务，向量检索为预留能力。

PowerContext 的作用

用户上下文记忆由 PowerContext 管理：按用户隔离 Scope，学习进度、搜索历史、浏览记录与偏好以 Atomic Memory 写入。启动 PowerContext Server 时通过 HTTP 调用真实服务（1.4.1），服务不可达时回退到本地兼容实现，页面顶部会显示当前实际后端。
