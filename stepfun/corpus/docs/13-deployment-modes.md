# seekdb 的嵌入式与服务器部署

嵌入式模式通过本地库文件运行，不需要单独启动服务进程，数据目录里包含日志、元数据和存储文件。它的优点是部署简单、没有网络开销，缺点是同一时间通常只允许一个进程打开数据库，不适合多用户并发。

服务器模式启动一个监听 2881 端口的进程，兼容 MySQL 协议。客户端用主机、端口、用户名、密码连接，可以多连接并发。容器化部署时把数据目录挂载到宿主机，重启容器不会丢数据。官方镜像为 oceanbase/seekdb，默认数据目录是 /var/lib/oceanbase。

选择哪一种取决于使用场景。个人知识库、桌面应用可以选嵌入式；团队共享、需要多个前端或后台任务时选服务器模式。本项目的浏览器端推理与数据库解耦，两种模式都能接入，只需要修改连接配置。

无论哪种模式，都要关注数据目录权限、磁盘空间和启动顺序。服务端启动需要几秒到几十秒完成初始化，应用应做重试与健康检查，而不是启动即查询。
