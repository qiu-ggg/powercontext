# seekdb 概览

seekdb 是 OceanBase 推出的 AI 原生搜索数据库，把关系数据、向量、全文和半结构化 JSON 放在同一个引擎里。它不是简单的向量插件，而是在存储层同时维护向量索引、倒排索引和标量索引，一条 SQL 就能完成多模态过滤与排序。

核心能力包括：兼容 MySQL 协议的 SQL 接口、HNSW 向量索引、支持 IK 与 ngram 的全文索引、JSON 字段过滤，以及 DBMS_HYBRID_SEARCH 这样的混合检索包。数据写入后立即可查，索引刷新可以显式触发，适合需要实时更新的知识库。

部署方式有两种。嵌入式模式把数据库作为库文件运行在应用进程内，适合个人工具和单机应用；服务器模式提供标准 MySQL 端口，适合多客户端共享和容器化部署。两种模式共用同一套 SQL 与索引定义。

对端侧应用来说，seekdb 通常部署在用户本机或局域网内的服务进程里，浏览器只负责推理和界面。这样既满足“推理在端侧”的要求，又能利用数据库成熟的索引与事务能力。
