# 端侧推理的隐私与安全

端侧推理的核心价值之一是数据不出设备。文档在浏览器里完成解析和向量化，原始文本只发送到本机的数据库服务，不经过云端推理 API。对于合同、病历、内部纪要这类敏感材料，这一点往往比性能更重要。

隐私承诺需要技术验证，而不是口号。网络面板应能证明没有向外部推理服务发请求；模型文件可以从本地静态目录加载；数据库连接指向 localhost。文档里应明确列出所有外部请求，例如模型下载和可选的遥测。

浏览器沙箱也带来限制。页面不能随意读取本地文件系统，导入文档需要用户主动选择或拖拽；跨域请求受同源策略约束；持久化存储可能被清理。应用要处理存储被清空后的重建流程。

安全上还要防止提示注入与越权。知识库内容是不可信输入，展示时要转义 HTML，避免脚本注入；多知识库场景要校验集合归属，防止通过修改请求参数读取其他知识库。
