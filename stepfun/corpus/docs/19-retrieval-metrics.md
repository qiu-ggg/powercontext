# 检索质量评测指标

Recall@K 衡量前 K 条结果里覆盖了多少相关文档。假设一条查询有三个相关文档，前五条命中两个，Recall@5 就是三分之二。它关注“有没有找全”，适合评估召回能力，但不区分相关文档排在第几位。

nDCG@K 同时考虑相关性和位置。每个结果按相关性打增益，再按名次做对数折损，最后除以理想排序的 DCG 做归一化。相关文档排得越靠前，得分越高。对于二值相关性，nDCG 对第一名是否正确尤其敏感。

MRR 只看第一个相关结果的名次，取倒数后平均。它适合问答类场景，用户通常只看第一条。Precision@K 衡量前 K 条里相关结果的比例，适合对噪声敏感的场景。

评测集要覆盖不同类型：精确术语、同义改写、多主题混合、否定与约束条件。每条查询标注相关文档，标注口径要一致。报告结果时要给出查询数量、K 值、语料规模，并说明是文档级还是块级相关性。单次结果波动大时，应重复多次并报告中位数或均值与方差。
