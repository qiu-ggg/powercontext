# 模型加载与浏览器缓存

模型文件通常有几十兆，重复下载会拖慢首屏。浏览器提供 HTTP 缓存与 Cache API 两层机制。静态资源服务器应返回带内容哈希的文件名和长期缓存头，让浏览器直接复用；Transformers.js 还会把模型文件写入 Cache Storage，按 URL 作为键。

冷启动包括下载、解析 ONNX 图、创建会话和首次推理。真正影响体验的是会话创建与着色器编译，这部分无法完全避免，但可以预热：应用启动后在后台加载模型并跑一条短文本，用户第一次搜索时就不用等待。

进度反馈很重要。模型下载和初始化可能持续数秒到数十秒，界面要显示当前阶段、已下载字节和百分比，而不是一个不动的转圈。失败时要给出可操作的提示，例如检查网络、切换镜像或改用更小的量化模型。

缓存要版本化。模型文件更新后，如果缓存键不变，用户可能一直使用旧权重。把模型版本或文件哈希拼进路径，可以避免脏缓存，也方便回滚。
