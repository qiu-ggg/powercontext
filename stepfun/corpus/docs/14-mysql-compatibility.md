# MySQL 协议兼容与 SQL 使用

seekdb 兼容 MySQL 协议与大部分语法，现有的 MySQL 客户端、ORM 和驱动可以直接连接。建表、索引、事务、JSON 函数这些常用能力都可用，开发者不需要学习一套新的查询语言。这对已有系统迁移非常友好。

扩展语法主要体现在向量与全文。向量列写作 VECTOR(维度)，建向量索引时用 VECTOR INDEX ... WITH (DISTANCE=cosine, TYPE=hnsw, LIB=vsag)；全文索引用 FULLTEXT INDEX ... WITH PARSER ik。混合检索通过 DBMS_HYBRID_SEARCH.GET_SQL 生成执行语句，传入 JSON 描述向量路、全文路、过滤条件和融合参数。

参数化查询要使用占位符，避免把用户输入直接拼进 SQL。向量字面量通常以字符串形式传入，例如 '[0.1,0.2,...]'，由数据库解析。表名和集合名不能用占位符，必须做白名单校验。

分页与过滤要下推到数据库。把向量检索的结果全部取回应用层再过滤，既浪费带宽又可能漏掉正确结果。seekdb 支持在向量检索里附加标量过滤，过滤条件应与向量检索在同一条语句中执行。
