# ONNX Runtime Web 的执行提供器

ONNX Runtime Web 是浏览器端的推理引擎，把 ONNX 计算图编译到不同后端执行。执行提供器（Execution Provider，EP）决定算子落在哪里：wasm EP 在 CPU 上运行，webgpu EP 把算子提交给 GPU，webnn 还在早期阶段。

选择 EP 时先做能力探测。navigator.gpu 存在并不代表一定可用，适配器请求可能失败，也可能缺少某些算子支持。稳妥的做法是尝试创建会话并跑一次小推理，成功后再切换到正式模型；失败则回退 wasm。

wasm EP 的性能取决于 SIMD、线程数和模型量化。启用多线程需要跨域隔离，线程数要与硬件并发匹配。webgpu EP 对小模型、小批量的收益不一定大，因为数据传输和调度开销占比高；批量推理时优势更明显。

调试时可以打开运行时日志，观察算子是否被回退到 CPU。混合执行很常见，部分不支持的算子会落到 wasm，导致性能低于预期。模型导出时应尽量使用运行时支持的算子集。
