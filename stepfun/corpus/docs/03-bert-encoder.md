# BERT 编码器与句向量

BERT 是只有编码器的 Transformer，由多层自注意力与前馈网络堆叠而成。输入文本先经过 WordPiece 分词，加上 [CLS] 与 [SEP] 特殊符号，再查表得到 token embedding，叠加位置编码后送入编码层。每一层都做多头注意力：把输入投影成 Query、Key、Value，计算缩放点积注意力，再经过残差连接和 LayerNorm。

句向量模型在 BERT 之上加一个池化层。常见做法有两种：取 [CLS] 位置的隐藏状态，或者对所有 token 的隐藏状态做平均池化。BGE 中文小模型 v1.5 推荐使用 CLS 池化，然后做 L2 归一化，使向量落在单位球面上。归一化之后，余弦相似度与内积等价，检索时可以直接用内积或余弦距离。

bge-small-zh-v1.5 有 4 层、隐藏维度 512、8 个注意力头，词表约两万一千，最大输入 512 个 token。它比 base 版本小很多，适合在浏览器里运行。层数少意味着表达能力有限，长文档和复杂推理型查询的召回会弱一些，需要靠混合检索和重排弥补。

编码器的计算量与序列长度近似平方相关，长文本推理明显更慢。工程上要把分块控制在几百个字符以内，既控制延迟，也避免超出 512 token 被截断。
