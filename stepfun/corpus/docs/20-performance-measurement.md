# 端侧性能测量方法

性能数据要可复现，首先要固定条件：同一台设备、同一浏览器版本、同一模型文件、同一语料和查询集。记录 CPU、内存、显卡、操作系统和浏览器版本，否则数字无法比较。

计时要用高精度时钟 performance.now()，并明确计时的起止范围。模型加载、文档向量化、数据库写入、索引刷新、查询向量化、数据库检索、端到端延迟要分开统计。端到端延迟从用户点击搜索开始，到结果渲染完成结束，包含网络与排队时间。

首次请求和预热后的请求要分开报告。首次包含模型下载、会话创建和缓存未命中的开销，通常是后续请求的数倍。至少重复五次，报告中位数，避免只挑最快的一次。对波动大的指标，同时给出最小值、最大值和标准差。

浏览器性能面板可以定位瓶颈：主线程阻塞、GPU 队列等待、WASM 编译、网络请求。把长任务拆到 Web Worker，避免界面卡顿。测量时关闭开发者工具的限速和节流选项，保持电源模式为高性能。
