# 中文分词与全文索引分析器

中文没有天然的词边界，全文索引必须先分词。IK 是常用的中文分词器，支持 smart 与 max_word 两种模式。smart 模式倾向于输出最细粒度且歧义少的切分，适合召回；max_word 模式会输出更多长词组合，适合精度优先的场景。seekdb 的全文索引可以通过 WITH PARSER ik 并附加 ik_mode 属性来启用。

ngram 分词器按固定长度滑窗切字，不依赖词典，召回高但索引膨胀明显。对于短文本、型号、代码片段较多的语料，ngram 往往更稳。space 分词器只按空白切分，适合英文或已经预分词的文本。

分词器在建模时就固定下来，写入和查询必须使用同一个分析器，否则词项对不上。修改分析器通常要重建索引。工程上应把分析器配置写进建表语句和技术文档，避免环境漂移。

停用词会过滤“的、了、是”等高频虚词。中文里这些词几乎不携带区分度，保留它们只会增加索引体积和噪声。但某些查询依赖虚词表达结构，过滤策略要结合语料验证。标点一般直接丢弃。
